## Yleiskuvaus

DemoScope parantaa Counter-Strike VACNetin tarkistussivuja. Käytä näppäimistöä valmiisiin arvioihin, klipin rajattuun hakuun, kuva-askeleisiin, tilapäiseen nopeutukseen, kaksivaiheiseen lähetykseen ja omien arvioidesi yksityiseen historiaan. Skripti tukee sekä perinteistä neljän kysymyksen lomaketta että uutta yhden kysymyksen tehtävää. Jos Valve muuttaa sivua, skripti poistuu turvallisesti käytöstä. Kaikki toimii paikallisesti selaimessa.

## Ominaisuudet

| | |
|---|---|
| **Tarkistustyö** | Viisi nopeaa arviota näppäimillä 1–5 ja 15 laajennettua yhdistelmää. Satunnaisvalinta on valinnainen ja oletuksena pois. Enter valmistelee lähetyksen, seuraava Enter lähettää; Esc peruuttaa. |
| **Molemmat tehtävätyypit** | Tunnistaa perinteisen lomakkeen (aim assist, wallhack, auto-bhop, botti) ja kysymyksen “Is the Subject cheating beyond a reasonable doubt?”. Uudessa tehtävässä on tiivis näkymä, arviot näppäimillä 1–3 ja klipin loppuun laskeva lukitusilmaisin. |
| **Klipin huomioiva soitin** | Aikajana rajataan klipin alkuun ja loppuun, hypyt ±5 sekuntia, kuva-askeleet 1/64 sekuntia, Shift-nopeutus (0,5×–4×), mykistys ja koko näytön pikanäppäin. |
| **Pikanäppäimet** | Määritä 18 toimintoa uudelleen omassa ikkunassa. Ristiriidat selitetään ennen korvaamista, ja sivun näppäinvihjeet seuraavat valintojasi. |
| **Animaatiot** | Kuusi ilmaisintyyliä, kolme nopeutta, päälle/pois ja reaaliaikainen esikatselu. Noudattaa oletuksena järjestelmän vähennetyn liikkeen asetusta. |
| **Selkeät arviot** | “?” selittää jokaisen luokan, ja tärkeät ilmaukset korostetaan, jotta kielto ei jää huomaamatta. |
| **Yksityinen paikallishistoria** | Klippi- ja pelikohtainen historia, JSON-tuonti/vienti, HTML-raportit ja varmuuskopioiden yhdistäminen. |
| **Kutsusivu** | Uudistettu /vacnet/createinvite: näytä/piilota, kopioi yhdellä napsautuksella, vaatimusyhteenveto, sulkemispainike ja Enter/Esc-pikanäppäimet. |
| **29 kieltä** | Käyttää valintaasi, Steamin ?l=-asetusta ja sitten selaimen kieltä. Kielivalinta vaihtaa myös VACNetin tekstit. |
| **Äänitehosteet** | Web Audio -äänet, äänenvoimakkuus, esikuuntelu ja kytkin. |
| **Kestää sivumuutoksia** | Alustusvaiheet eristetään ja tärkeille elementeille on varahaut. Tunnistamattomalla sivulla DemoScope poistuu käytöstä muuttamatta VACNetiä. Diagnostiikan voi kopioida virheraporttiin. |

## Asennus

1. Asenna [Tampermonkey](https://www.tampermonkey.net/) tai [Violentmonkey](https://violentmonkey.github.io/). Skripti käyttää GM_addStyle- ja unsafeWindow-rajapintoja.
2. [Asenna DemoScope](https://raw.githubusercontent.com/ebayybe/DemoScope/main/DemoScope.user.js) ja vahvista asennus.
3. Kirjaudu Steamiin ja avaa [counter-strike.net/vacnet](https://www.counter-strike.net/vacnet/).
4. Avaa tarkistusklippi. Skripti käynnistyy automaattisesti; /vacnet/join ei kuulu mukaan.

Päivitykset tulevat userscript-hallinnan kautta. DemoScope toimii Chromium-pohjaisissa selaimissa ja Firefoxissa.

## Pikanäppäimet

Pikanäppäimet toimivat, kun kohdistus ei ole muokattavassa kentässä tai muussa ohjaimessa. **Kaikkia näppäimiä voi muuttaa kohdassa Asetukset → Pikanäppäimet.**

| Näppäin | Toiminto |
|---|---|
| 1–5 | Perinteisen lomakkeen profiilit: botti + aim + wallhack, aim + wallhack, rage, puhdas pelaaja tai epävarma. |
| 1–3 | Yhden kysymyksen tehtävä: huijaus / epävarma / ei havaittua huijausta. |
| Enter | Vahvista; perinteisessä lomakkeessa ensimmäinen painallus valmistelee, seuraava lähettää. |
| Esc | Peruuta vahvistusta odottava arvio tai nollaa ensimmäinen Enter. |
| Shift (pidä) | Nopeutus 0,5×–4×, oletus 2×. |
| ← → | Hyppää 5 sekuntia taakse/eteen. |
| , . | Siirry yksi kuva (1/64 s) taakse/eteen. |
| Space | Toista/tauko. |
| M / F | Mykistä/koko näyttö; kaksoisnapsautus vaihtaa myös koko näytön tilaa. |
| F2 | Avaa asetukset. |
| Enter / Esc (kutsusivu) | Valmis/sulje. |

## Mukauttaminen

Avaa asetukset F2:lla. Pikanäppäimiä voi nollata yksittäin tai kaikki kerralla; ristiriidan voi korvata, vaihtaa tai peruuttaa. Animaatioissa on kuusi tyyliä ja kolme nopeutta. Äänet voi kytkeä, säätää ja testata. Paikallishistorialle voi asettaa rajat ja viedä JSON-/HTML-tiedostoja. Piilota haluamasi alatunnisteen osat. Diagnostiikka kopioidaan virheraportteihin. Nollaus palauttaa äänen, pikanäppäimet ja animaatiot, mutta säilyttää historian.

## Kielet

DemoScope tukee bulgariaa, kiinaa (yksinkertaistettu ja perinteinen), tšekkiä, tanskaa, hollantia, englantia, suomea, ranskaa, saksaa, kreikkaa, unkaria, indonesiaa, italiaa, japania, koreaa, norjaa, puolaa, portugalia (Portugali ja Brasilia), romaniaa, venäjää, espanjaa (Espanja ja Latinalainen Amerikka), ruotsia, thaita, turkkia, ukrainaa ja vietnamia. Vaihda kieli sivun valitsimesta milloin tahansa.

## Ongelman ilmoittaminen

Valve voi muuttaa VACNet-sivuja varoittamatta. Paina F2, avaa **Diagnostiikka**, valitse **Kopioi diagnostiikka** ja liitä teksti uuteen [ilmoitukseen](https://github.com/ebayybe/DemoScope/issues), mielellään kuvakaappauksen kanssa. Raportti sisältää version, ajan, selaimen kielen ja user-agentin, löydetyt elementit, epäonnistuneet alustusvaiheet ja sivun rakenteen (tagit, id:t ja luokat), mutta ei sivutekstiä, tilin nimeä tai historiaa. VACNet toimii normaalisti, vaikka DemoScope poistuisi käytöstä.

## Usein kysyttyä

<details><summary><b>Miksi DemoScope poistui käytöstä tällä sivulla?</b></summary>

VACNetin sivurakenne muuttui eikä sitä enää tunnisteta. Skripti poistuu, jotta sivua ei jätetä puolivalmiiksi. Kopioi diagnostiikka ja ilmoita ongelmasta.
</details>

<details><summary><b>Miksi VACNetin kieli eroaa DemoScopesta?</b></summary>

DemoScope pyytää kieltä Steamin ?l=-parametrilla. Jos VACNetiltä puuttuu käännös, se käyttää oletuskieltään ja DemoScopen tekstit säilyvät valitulla kielellä.
</details>

<details><summary><b>Valitseeko DemoScope arviot puolestani?</b></summary>

Ei. Esivalinta painaa vain valitsemiasi painikkeita ja sinä vahvistat lähetyksen. Tarkista jokainen klippi ja noudata ohjelman sääntöjä.
</details>

<details><summary><b>Tallentuuko yhden kysymyksen tehtävä historiaan?</b></summary>

Ei vielä. Paikallinen historia tallentuu toistaiseksi vain perinteisestä neljän kysymyksen lomakkeesta.
</details>

<details><summary><b>Miten palautan oletusnäppäimet?</b></summary>

Käytä muutetun näppäimen palautuskuvaketta, pikanäppäinikkunan “Palauta kaikki” -toimintoa tai asetusten “Palauta”-toimintoa.
</details>

## Rakenne

DemoScope on yksi itse käynnistyvä funktio, joka suoritetaan document-start-vaiheessa eikä kehyksissä. init() tunnistaa sivutyypin ja liittää moduulit. Kaikkien 217 ylätason funktion, parametrien, palautusarvojen ja tallennusavainten viite on tiedostossa [fi_FUNCTIONS.md](https://github.com/ebayybe/DemoScope/blob/main/docs/fi_FUNCTIONS.md).

## Tietosuoja

DemoScope ei lähetä telemetriaa eikä lataa asetuksia tai historiaa palvelimelle. VACNet saa arviot sivuston normaalin lomakkeen kautta. Tiedot pysyvät selaimen localStorage-tallennuksessa (demoscope-etuliitteiset avaimet) ja sessionStorage-tallennuksessa. Tyhjennä historia kohdassa **Asetukset → Paikallishistoria → Tyhjennä historia**. Diagnostiikka kopioidaan vain leikepöydälle; päätät itse sen jakamisesta.

## Vastuuvapauslauseke

DemoScope on epävirallinen yhteisöprojekti, jota Valve Corporation ei ole hyväksynyt eikä johon se ole sidoksissa. Se ei tee päätöksiä puolestasi. Tarkista klipit itse ja noudata ohjelman sääntöjä. Käyttö omalla vastuulla.
