## ภาพรวม

DemoScope ปรับปรุงหน้าตรวจสอบของ Counter-Strike VACNet ให้ใช้งานสะดวกขึ้น คุณสามารถใช้คีย์บอร์ดเลือกชุดคำตัดสิน เลื่อนดูเฉพาะช่วงคลิปที่ตรวจสอบ ก้าวทีละเฟรม เพิ่มความเร็วชั่วคราว ส่งคำตัดสินแบบสองขั้นตอน และเก็บประวัติส่วนตัวของคำตัดสินได้ สคริปต์รองรับทั้งแบบฟอร์มเดิม 4 คำถามและงานรูปแบบใหม่ 1 คำถาม หาก Valve เปลี่ยนหน้าเว็บ สคริปต์จะปิดตัวอย่างปลอดภัย ทุกอย่างทำงานในเบราว์เซอร์ของคุณ

## การติดตั้ง

1. ติดตั้งตัวจัดการ userscript เช่น [Tampermonkey](https://www.tampermonkey.net/) หรือ [Violentmonkey](https://violentmonkey.github.io/) สคริปต์ใช้ GM_addStyle และ unsafeWindow
2. [ติดตั้ง DemoScope](https://raw.githubusercontent.com/ebayybe/DemoScope/main/DemoScope.user.js) และยืนยันในตัวจัดการ
3. ลงชื่อเข้าใช้ Steam แล้วเปิด [counter-strike.net/vacnet](https://www.counter-strike.net/vacnet/)
4. เปิดคลิปตรวจสอบ DemoScope จะเริ่มทำงานเอง ยกเว้นหน้า /vacnet/join

ตัวจัดการ userscript จะส่งการอัปเดตให้ รองรับเบราว์เซอร์ Chromium และ Firefox

## ปุ่มลัดคีย์บอร์ด

ปุ่มลัดทำงานในหน้าตรวจสอบเมื่อไม่ได้โฟกัสช่องแก้ไขหรือส่วนควบคุมอื่น **เปลี่ยนปุ่มทั้งหมดได้ที่ การตั้งค่า → ปุ่มลัด**

| ปุ่ม | การทำงาน |
|---|---|
| 1–5 | แบบฟอร์มเดิม: ชุด bot + aim + wallhack, aim + wallhack, rage, ผู้เล่นสะอาด หรือไม่แน่ใจ |
| 1–3 | งานคำถามเดียว: โกง / ไม่แน่ใจ / ไม่พบการโกง |
| Enter | ยืนยัน แบบฟอร์มเดิมกดครั้งแรกเพื่อเตรียม แล้วกดอีกครั้งเพื่อส่ง |
| Esc | ยกเลิกคำตัดสินที่รอยืนยัน หรือยกเลิกการเตรียมจาก Enter ครั้งแรก |
| Shift (กดค้าง) | เร่งความเร็ว 0.5×–4× ค่าเริ่มต้น 2× |
| ← → | ย้อน/เดินหน้า 5 วินาที |
| , . | ย้อน/เดินหน้าทีละเฟรม (1/64 วินาที) |
| Space | เล่น/หยุดชั่วคราว |
| M / F | ปิดเสียง/เต็มหน้าจอ ดับเบิลคลิกวิดีโอก็สลับเต็มหน้าจอได้ |
| F2 | เปิดหน้าต่างการตั้งค่า |
| Enter / Esc (หน้าคำเชิญ) | เสร็จ/ปิด |

## การปรับแต่ง

กด F2 เพื่อเปิดการตั้งค่า ปรับปุ่มลัดทีละปุ่มหรือทั้งหมด และจัดการปุ่มชนกันด้วยการแทนที่ สลับ หรือยกเลิก แอนิเมชันมี 6 สไตล์และ 3 ความเร็ว เสียงเปิด/ปิด ปรับระดับและทดสอบได้ ประวัติในเครื่องตั้งขีดจำกัดและส่งออก JSON/HTML ได้ ซ่อนส่วนต่าง ๆ ของท้ายหน้าได้ รายงานวินิจฉัยคัดลอกไว้แจ้งปัญหาได้ การรีเซ็ตคืนค่าเสียง ปุ่มลัด และแอนิเมชัน แต่เก็บประวัติไว้

## ภาษา

DemoScope มี 29 ภาษา ได้แก่ บัลแกเรีย จีนตัวย่อและตัวเต็ม เช็ก เดนมาร์ก ดัตช์ อังกฤษ ฟินแลนด์ ฝรั่งเศส เยอรมัน กรีก ฮังการี อินโดนีเซีย อิตาลี ญี่ปุ่น เกาหลี นอร์เวย์ โปแลนด์ โปรตุเกส (โปรตุเกสและบราซิล) โรมาเนีย รัสเซีย สเปน (สเปนและลาตินอเมริกา) สวีเดน ไทย ตุรกี ยูเครน และเวียดนาม เปลี่ยนได้จากตัวเลือกภาษาในหน้าเว็บ

## รายงานปัญหา

Valve อาจเปลี่ยนหน้า VACNet โดยไม่แจ้งล่วงหน้า หากมีบางอย่างใช้ไม่ได้ กด F2 เปิด **การวินิจฉัย** แล้วเลือก **คัดลอกข้อมูลวินิจฉัย** จากนั้นวางใน [issue ใหม่](https://github.com/ebayybe/DemoScope/issues) และแนบภาพหน้าจอถ้าทำได้ รายงานมีเวอร์ชัน เวลา ภาษาและ user-agent ของเบราว์เซอร์ องค์ประกอบที่พบ ขั้นตอนเริ่มต้นที่ล้มเหลว และโครงสร้างหน้า (แท็ก id และ class เท่านั้น) ไม่มีข้อความหน้า ชื่อบัญชี หรือประวัติ แม้ DemoScope ปิดตัว VACNet ยังคงทำงานตามปกติ

## คำถามที่พบบ่อย

<details><summary><b>ทำไม DemoScope จึงปิดการทำงานในหน้านี้?</b></summary>

หน้า VACNet เปลี่ยนไปจนสคริปต์จำไม่ได้ สคริปต์จึงหยุดเพื่อไม่ให้หน้าเว็บอยู่ในสภาพแก้ไขไม่สมบูรณ์ คัดลอกข้อมูลวินิจฉัยแล้วสร้าง issue
</details>

<details><summary><b>ทำไมภาษา VACNet จึงต่างจาก DemoScope?</b></summary>

DemoScope ขอภาษาให้ VACNet ผ่านพารามิเตอร์ ?l= ของ Steam หาก VACNet ไม่มีคำแปล จะใช้ภาษาเริ่มต้นของตน แต่ป้ายกำกับ DemoScope ยังคงใช้ภาษาที่เลือก
</details>

<details><summary><b>DemoScope เลือกคำตัดสินแทนฉันหรือไม่?</b></summary>

ไม่ ชุดสำเร็จรูปกดเฉพาะปุ่มที่คุณเลือก และคุณต้องยืนยันการส่งเอง ตรวจสอบทุกคลิปด้วยตนเองและทำตามกฎของโปรแกรม
</details>

<details><summary><b>งานคำถามเดียวถูกบันทึกในประวัติหรือไม่?</b></summary>

ยังไม่บันทึก ขณะนี้ประวัติในเครื่องรองรับเฉพาะแบบฟอร์มเดิมสี่คำถาม
</details>

<details><summary><b>คืนค่าปุ่มเริ่มต้นได้อย่างไร?</b></summary>

ใช้ไอคอนรีเซ็ตข้างปุ่มที่เปลี่ยน เลือก “รีเซ็ตทั้งหมด” ในหน้าต่างปุ่มลัด หรือ “รีเซ็ต” ในหน้าต่างการตั้งค่า
</details>

## สถาปัตยกรรม

DemoScope เป็นฟังก์ชันทำงานด้วยตัวเองหนึ่งชุด เริ่มที่ document-start และไม่ทำงานในเฟรม init() เลือกชนิดหน้า ตรวจสอบว่าจำหน้าได้ แล้วเชื่อมโมดูลต่าง ๆ เอกสารอ้างอิงฟังก์ชันระดับบนทั้ง 217 รายการ พารามิเตอร์ ค่าที่ส่งกลับ และคีย์จัดเก็บอยู่ใน [th_FUNCTIONS.md](https://github.com/ebayybe/DemoScope/blob/main/docs/th_FUNCTIONS.md)

| Local history | ประวัติ ข้อมูลสำรอง และรายงาน | appendReviewHistory, importLocalHistory, exportCombinedHistoryReports |
| Settings & animations | หน้าต่างตั้งค่า เสียง และแอนิเมชัน | ensureSettingsDialog, installExtraSettingsSections, ensureAnimationsDialog, playUiSound |
| Invite page | หน้าเชิญเพื่อน ปุ่มปิด และปุ่มลัด | installInvitePage, installInviteExtras |
| Resilience | ขั้นตอนแยกอิสระ การค้นหาสำรอง ปิดสคริปต์ และวินิจฉัย | safeStep, disableDemoScope, buildDiagnosticsReport |
| Bootstrap | จุดเริ่มต้น | init, enhanceLayout |
</details>

## ความเป็นส่วนตัว

DemoScope ไม่ส่ง telemetry และไม่อัปโหลดการตั้งค่าหรือประวัติ VACNet รับคำตัดสินผ่านแบบฟอร์มปกติของเว็บไซต์ ข้อมูลอยู่ใน localStorage ของเบราว์เซอร์ (คีย์ขึ้นต้นด้วย demoscope) และ sessionStorage ลบประวัติได้ที่ **การตั้งค่า → ประวัติในเครื่อง → ล้างประวัติ** รายงานวินิจฉัยคัดลอกไปยังคลิปบอร์ดเท่านั้น คุณเป็นผู้ตัดสินใจว่าจะแชร์หรือไม่

## ข้อจำกัดความรับผิด

DemoScope เป็นโครงการชุมชนที่ไม่เป็นทางการ ไม่ได้เกี่ยวข้องหรือรับรองโดย Valve Corporation และไม่ตัดสินแทนคุณ ตรวจสอบทุกคลิปด้วยตนเองและทำตามกฎของโปรแกรม ใช้งานโดยยอมรับความเสี่ยงเอง
