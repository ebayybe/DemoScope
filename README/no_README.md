## Oversikt

DemoScope forbedrer Counter-Strike VACNet-sidene for gjennomgang. Bruk tastaturet til forhåndsvalgte vurderinger, søk begrenset til klippet, bilderamme-for-bilderamme-steg, midlertidig hastighetsøkning, innsending i to trinn og privat historikk over dine egne vurderinger. Det støtter både det klassiske skjemaet med fire spørsmål og den nyere oppgaven med ett spørsmål. Hvis Valve endrer siden, slås skriptet trygt av. Alt kjører lokalt i nettleseren.

## Funksjoner

| | |
|---|---|
| **Arbeidsflyt** | Fem hurtigvalg på 1–5 og 15 utvidede kombinasjoner. Tilfeldig vurdering er valgfritt og av som standard. Enter klargjør innsendingen; neste Enter sender. Esc avbryter. |
| **Begge oppgavetyper** | Oppdager klassisk skjema (aim assist, wallhack, auto-bhop, bot) og spørsmålet “Is the Subject cheating beyond a reasonable doubt?”. Ny oppgave får kompakt layout, merkede valg på 1–3 og en låseindikator som teller ned til klippet er ferdig. |
| **Klippbevisst spiller** | Tidslinje begrenset til klippets start/slutt, hopp på ±5 sekunder, bilderammesteg på 1/64 sekund, Shift-hastighet (0,5×–4×), demping og fullskjermsnarvei. |
| **Hurtigtaster** | Tilordne 18 handlinger på nytt i eget vindu. Konflikter forklares før noe erstattes, og tastetips følger innstillingene dine. |
| **Animasjoner** | Liveforhåndsvisning med seks indikatorstiler, tre hastigheter og av/på. Følger systemets innstilling for redusert bevegelse som standard. |
| **Forståelige vurderinger** | Et “?” forklarer hver kategori, og viktige uttrykk utheves slik at “ikke” ikke overses. |
| **Privat lokal historikk** | Historikk per klipp og kamp, JSON-import/eksport, HTML-rapporter og sammenslåing av sikkerhetskopier. |
| **Invitasjonsside** | Ny /vacnet/createinvite-side med vis/skjul, kopiering med ett klikk, kravoversikt, lukkeknapp og Enter/Esc-snarveier. |
| **29 språk** | Bruker valget ditt, Steams ?l=-innstilling og deretter nettleserspråket. Språkvalget endrer også VACNets tekst. |
| **Lydeffekter** | Syntetiske Web Audio-signaler med volum, forhåndslytting og av/på. |
| **Robusthet** | Isolerte oppstartstrinn og reserveoppslag. Hvis siden ikke gjenkjennes, deaktiveres DemoScope uten å endre VACNet. Diagnostikk kan kopieres til feilrapporter. |

## Installasjon

1. Installer [Tampermonkey](https://www.tampermonkey.net/) eller [Violentmonkey](https://violentmonkey.github.io/). Skriptet bruker GM_addStyle og unsafeWindow.
2. [Installer DemoScope](https://raw.githubusercontent.com/ebayybe/DemoScope/main/DemoScope.user.js), og bekreft installasjonen.
3. Logg inn på Steam og åpne [counter-strike.net/vacnet](https://www.counter-strike.net/vacnet/).
4. Åpne et gjennomgangsklipp. Skriptet starter automatisk; /vacnet/join er unntatt.

Oppdateringer leveres gjennom userscript-behandleren. DemoScope fungerer i Chromium-baserte nettlesere og Firefox.

## Hurtigtaster

Snarveiene fungerer når fokus ikke er i et redigerbart felt eller en annen kontroll. **Alle taster kan endres under Innstillinger → Hurtigtaster.**

| Tast | Handling |
|---|---|
| 1–5 | Klassisk skjema: forhåndsvalg for bot + aim + wallhack, aim + wallhack, rage, ren spiller eller usikker. |
| 1–3 | Én oppgave: juks / usikker / ingen juks sett. |
| Enter | Bekreft; i klassisk skjema klargjør første trykk, neste sender. |
| Esc | Avbryt vurdering som venter, eller nullstill første Enter. |
| Shift (hold) | Hastighet 0,5×–4×, standard 2×. |
| ← → | Hopp 5 sekunder tilbake/frem. |
| , . | Gå én bilderamme (1/64 sekund) tilbake/frem. |
| Space | Spill av/pause. |
| M / F | Demp/fullskjerm; dobbeltklikk bytter også fullskjerm. |
| F2 | Åpne innstillingene. |
| Enter / Esc (invitasjon) | Ferdig/lukk. |

## Tilpasning

Åpne innstillingene med F2. Hurtigtaster kan tilbakestilles enkeltvis eller samlet; konflikter kan erstattes, byttes eller avbrytes. Animasjoner har seks stiler og tre hastigheter. Lyder kan slås av/på, justeres og testes. Lokal historikk har grenser og JSON-/HTML-eksport. Du kan skjule deler av bunnteksten. Diagnostikk kopieres til feilrapporter. Tilbakestilling gjenoppretter lyd, hurtigtaster og animasjoner, men beholder historikken.

## Rapporter et problem

Valve kan endre VACNet-sidene uten varsel. Trykk F2, åpne **Diagnostikk**, velg **Kopier diagnostikk**, og lim inn teksten i en ny [sak](https://github.com/ebayybe/DemoScope/issues), gjerne med et skjermbilde. Rapporten inneholder versjon, tidspunkt, nettleserspråk, user-agent, funne sideelementer, oppstartstrinn som feilet og sidens struktur (tagger, id-er og klasser), men ikke sidetekst, kontonavn eller historikk. VACNet fortsetter normalt selv om DemoScope slår seg av.

## Vanlige spørsmål

<details><summary><b>Hvorfor ble DemoScope deaktivert på siden?</b></summary>

VACNet-siden er endret og gjenkjennes ikke lenger. Skriptet trekker seg tilbake for ikke å etterlate siden halvferdig. Kopier diagnostikken og opprett en sak.
</details>

<details><summary><b>Hvorfor har VACNet et annet språk?</b></summary>

DemoScope ber VACNet bruke språket via Steams ?l=-parameter. Hvis oversettelsen mangler, bruker VACNet standardspråket sitt, mens DemoScopes etiketter beholder valget ditt.
</details>

<details><summary><b>Velger DemoScope vurderinger for meg?</b></summary>

Nei. Forhåndsvalgene trykker bare på knappene du valgte, og du bekrefter alltid innsendingen. Gå gjennom hvert klipp selv og følg reglene.
</details>

<details><summary><b>Lagres historikk for én-spørsmålsoppgaven?</b></summary>

Ikke ennå. Historikk lagres foreløpig bare for det klassiske skjemaet med fire spørsmål.
</details>

<details><summary><b>Hvordan gjenoppretter jeg standardtastene?</b></summary>

Bruk tilbakestillingsikonet ved en endret tast, «Tilbakestill alle» i hurtigtastvinduet eller «Tilbakestill» i innstillingene.
</details>

Referansen for alle 217 funksjoner, parametere, returverdier og lagringsnøkler finnes i [no_FUNCTIONS.md](https://github.com/ebayybe/DemoScope/blob/main/docs/no_FUNCTIONS.md).

## Personvern

DemoScope sender ingen telemetri og laster ikke opp innstillinger eller historikk. VACNet mottar vurderinger via sitt vanlige skjema. Data lagres i nettleserens localStorage (nøkler med prefikset demoscope) og sessionStorage. Slett historikken under **Innstillinger → Lokal historikk → Tøm historikk**. Diagnostikk kopieres bare til utklippstavlen; du bestemmer om du deler den.
