## Επισκόπηση

Το DemoScope βελτιώνει τις σελίδες αξιολόγησης Counter-Strike VACNet (`counter-strike.net/vacnet`). Αντί να κάνετε κλικ στη φόρμα ετυμηγορίας για κάθε σύντομο clip, χρησιμοποιείτε το πληκτρολόγιο: προεπιλογές ετυμηγορίας, γραμμή αναζήτησης περιορισμένη στο τμήμα που εξετάζετε, βήμα ανά καρέ, προσωρινή επιτάχυνση, υποβολή σε δύο βήματα και ιδιωτικό ιστορικό των δικών σας ετυμηγοριών. Υποστηρίζει και τις δύο μορφές που χρησιμοποιεί σήμερα το VACNet (την κλασική με τέσσερις ερωτήσεις και τη νέα εργασία μίας ερώτησης) και προστατεύεται όταν η Valve αλλάζει τη σελίδα. Όλα εκτελούνται τοπικά στο πρόγραμμα περιήγησής σας.

## Λειτουργίες

| | |
|---|---|
| **Ροή αξιολόγησης** | 5 γρήγορες προεπιλογές ετυμηγορίας στα `1`–`5` και 15 εκτεταμένοι συνδυασμοί, προαιρετικός τυχαιοποιητής (απενεργοποιημένος από προεπιλογή) και ασφαλής υποβολή δύο βημάτων: το `Enter` οπλίζει το κουμπί και ένα δεύτερο `Enter` στέλνει. Το `Esc` ακυρώνει. |
| **Και οι δύο τύποι εργασίας** | Εντοπίζει την κλασική φόρμα (βοήθεια σκόπευσης, wallhack, auto-bhop, bot) και την εργασία μίας ερώτησης («Is the Subject cheating beyond a reasonable doubt?»). Η δεύτερη χρησιμοποιεί συμπαγή διάταξη, ετικέτες ετυμηγορίας στα `1`–`3` και ένδειξη κλειδώματος έως το τέλος του clip. |
| **Player με όρια clip** | Η γραμμή και ο χρόνος περιορίζονται στην αρχή και στο τέλος του clip, άλματα ±5 s, βήμα καρέ 1/64 s, επιτάχυνση με πατημένο `Shift` (0,5×–4×), σίγαση και πλήρης οθόνη με συντομεύσεις. |
| **Συντομεύσεις υπό τον έλεγχό σας** | Αντιστοιχίστε ξανά οποιαδήποτε από τις 18 ενέργειες σε ειδικό παράθυρο. Οι συγκρούσεις εξηγούνται πριν από αντικατάσταση (ενέργεια, ομάδα και λειτουργία) και όλες οι υποδείξεις πλήκτρων ακολουθούν τις ρυθμίσεις σας. |
| **Κινούμενα εφέ** | Παράθυρο ζωντανής προεπισκόπησης με έξι στυλ ένδειξης, τρεις ταχύτητες και διακόπτη. Σέβεται από προεπιλογή τη ρύθμιση συστήματος «μείωση κίνησης». |
| **Κατανοητές ετυμηγορίες** | Ένα «?» δίπλα σε κάθε κατηγορία εξηγεί τη σημασία της, ενώ οι βασικές φράσεις επισημαίνονται για να μην παραβλέπεται το «not». |
| **Ιδιωτικό τοπικό ιστορικό** | Ιστορικό ανά clip και παιχνίδι στο `localStorage`, εισαγωγή/εξαγωγή JSON, αναφορές HTML και συγχώνευση πολλών αντιγράφων ασφαλείας σε μία αναφορά. |
| **Σελίδα πρόσκλησης** | Ανανεωμένη σελίδα `/vacnet/createinvite` με εμφάνιση/απόκρυψη, αντιγραφή με ένα κλικ, σύνοψη απαιτήσεων, κουμπί κλεισίματος και συντομεύσεις `Enter` / `Esc`. |
| **29 γλώσσες** | Χρησιμοποιεί πρώτα τη δική σας επιλογή, έπειτα τη ρύθμιση Steam `?l=` και τέλος τη γλώσσα του προγράμματος περιήγησης. Η επιλογή γλώσσας στο DemoScope αλλάζει και το κείμενο VACNet. |
| **Ηχητικά εφέ** | Συνθετικά σήματα Web Audio με ένταση, προεπισκόπηση και διακόπτη ενεργοποίησης. |
| **Έτοιμο για ανασχεδιασμούς** | Τα βήματα ρύθμισης είναι απομονωμένα, τα βασικά στοιχεία έχουν εναλλακτικές αναζητήσεις και, αν η σελίδα δεν αναγνωρίζεται, το DemoScope απενεργοποιείται χωρίς να πειράζει το VACNet. Με ένα κλικ αντιγράφεται διαγνωστική αναφορά για αναφορά σφάλματος. |

## Εγκατάσταση

1. Εγκαταστήστε έναν διαχειριστή userscript, όπως [Tampermonkey](https://www.tampermonkey.net/) ή [Violentmonkey](https://violentmonkey.github.io/). Το script χρησιμοποιεί `GM_addStyle` και `unsafeWindow`.
2. [**Εγκαταστήστε το DemoScope**](https://raw.githubusercontent.com/ebayybe/DemoScope/main/DemoScope.user.js) και επιβεβαιώστε την εγκατάσταση στον διαχειριστή.
3. Συνδεθείτε στο Steam και ανοίξτε το [counter-strike.net/vacnet](https://www.counter-strike.net/vacnet/).
4. Ανοίξτε ένα clip αξιολόγησης. Το DemoScope φορτώνει αυτόματα (η σελίδα `/vacnet/join` εξαιρείται).

Οι ενημερώσεις έρχονται μέσω του διαχειριστή userscript. Το DemoScope λειτουργεί σε προγράμματα περιήγησης Chromium και Firefox.

## Συντομεύσεις πληκτρολογίου

Οι συντομεύσεις λειτουργούν στις σελίδες αξιολόγησης όταν η εστίαση δεν βρίσκεται σε επεξεργάσιμο πεδίο ή άλλο διαδραστικό στοιχείο. **Κάθε παρακάτω πλήκτρο μπορεί να αλλάξει** από το **Settings → Hotkeys**.

| Πλήκτρο | Ενέργεια |
|---|---|
| `1` … `5` | Κλασική φόρμα: εφαρμογή προεπιλογής (1 bot + σκόπευση + wallhack, 2 σκόπευση + wallhack, 3 rage, 4 καθαρός παίκτης, 5 αβέβαιο). |
| `1` `2` `3` | Εργασία μίας ερώτησης: Cheating / Not sure / No cheats seen. |
| `Enter` | Επιβεβαίωση. Στην κλασική φόρμα, πατήστε μία φορά για όπλιση και ξανά για αποστολή. |
| `Esc` | Ακύρωση ετυμηγορίας που περιμένει επιβεβαίωση ή απενεργοποίηση του πρώτου `Enter`. |
| `Shift` (κρατήστε) | Επιτάχυνση (0,5×–4×, προεπιλογή 2×, επιλέγεται στη σελίδα). |
| `←` `→` | Μετάβαση 5 δευτερόλεπτα πίσω / μπροστά. |
| `,` `.` | Ένα καρέ πίσω / μπροστά (1/64 s). |
| `Space` | Αναπαραγωγή / παύση. |
| `M` / `F` | Σίγαση / πλήρης οθόνη (διπλό κλικ στο βίντεο αλλάζει επίσης την πλήρη οθόνη). |
| `F2` | Άνοιγμα παραθύρου ρυθμίσεων. |
| `Enter` / `Esc` *(σελίδα πρόσκλησης)* | Ολοκλήρωση / κλείσιμο. |

## Προσαρμογή

Ανοίξτε τις ρυθμίσεις με `F2`. Είναι ταξινομημένες από τις πιο συχνές προς τις λιγότερο συχνές:

- **Hotkeys**: ειδικό παράθυρο με όλες τις ενέργειες ομαδοποιημένες ανά σκοπό, επαναφορά ανά ενέργεια, «Reset all» και χειρισμό συγκρούσεων με **Replace**, **Swap** ή **Cancel**. Το `Esc` μπορεί να αντιστοιχιστεί όπως κάθε άλλο πλήκτρο.
- **Animations**: επιλέξτε στυλ (pulse, breathe, ripple, heartbeat, orbit, blink), ταχύτητα ή απενεργοποιήστε τα εφέ. Κάθε κάρτα εμφανίζει ζωντανή προεπισκόπηση.
- **Sound effects**: ενεργοποίηση/απενεργοποίηση, ένταση (ρυθμίζεται και με τον τροχό του ποντικιού) και κουμπί δοκιμής.
- **Local history**: ενεργοποίηση/απενεργοποίηση, όρια (10/20/30/50 εγγραφές ανά κλειδί, 100/200/300/500 κλειδιά), ώρα 12/24 ωρών, αντίγραφα JSON και αναφορές HTML.
- **Footer**: απόκρυψη συνδέσμου σχολίων, συνδέσμου αναφοράς, γραμμής πνευματικών δικαιωμάτων ή ολόκληρου του υποσέλιδου.
- **Diagnostics**: αντιγραφή αναφοράς για αναφορά σφάλματος (δείτε [Αναφορά προβλήματος](#αναφορά-προβλήματος)).
- **Reset**: ένα κουμπί επαναφέρει τις προεπιλογές ήχου, συντομεύσεων και κινήσεων. Το ιστορικό διατηρείται.

## Αναφορά προβλήματος

Η Valve αλλάζει τις σελίδες VACNet χωρίς προειδοποίηση. Αν κάτι σταματήσει να λειτουργεί:

1. Πατήστε `F2`, ανοίξτε τα **Diagnostics** και επιλέξτε **Copy diagnostics**.
2. Επικολλήστε το κείμενο σε ένα νέο [issue](https://github.com/ebayybe/DemoScope/issues), μαζί με στιγμιότυπο οθόνης αν μπορείτε.

Η αναφορά περιέχει την έκδοση του script, την ώρα, τη γλώσσα και το user-agent του προγράμματος περιήγησης, ποια στοιχεία εντοπίστηκαν, ποια βήματα ρύθμισης απέτυχαν και τη δομή της σελίδας (μόνο tags, ID και classes). Δεν περιέχει κείμενο σελίδας, όνομα λογαριασμού ή ιστορικό. Αν η σελίδα δεν αναγνωρίζεται, το DemoScope απενεργοποιείται εκεί και το αναφέρει· το VACNet συνεχίζει να λειτουργεί κανονικά.

## Συχνές ερωτήσεις

<details>
<summary><b>Το DemoScope λέει ότι απενεργοποιήθηκε σε αυτή τη σελίδα. Τι συνέβη;</b></summary>

Η σελίδα VACNet δεν ταιριάζει πλέον με όσα αναμένει το DemoScope, οπότε το script αποσύρθηκε αντί να αφήσει μισοφτιαγμένη διεπαφή. Αντιγράψτε τα διαγνωστικά (δείτε παραπάνω) και ανοίξτε issue· συνήθως ακολουθεί γρήγορα ενημέρωση.
</details>

<details>
<summary><b>Το κείμενο ετυμηγορίας VACNet είναι σε άλλη γλώσσα από το DemoScope.</b></summary>

Η επιλογή γλώσσας στο DemoScope ζητά από το VACNet το αντίστοιχο κείμενο μέσω της παραμέτρου Steam `?l=`. Αν δεν υπάρχει μετάφραση στο VACNet, χρησιμοποιεί την προεπιλεγμένη γλώσσα του, ενώ οι ετικέτες του DemoScope παραμένουν στη γλώσσα σας.
</details>

<details>
<summary><b>Το DemoScope επιλέγει ετυμηγορίες για μένα;</b></summary>

Όχι. Οι προεπιλογές πατούν μόνο τα κουμπιά ετυμηγορίας που επιλέξατε και εσείς επιβεβαιώνετε πάντα την υποβολή. Ελέγχετε κάθε clip μόνοι σας και τηρείτε τους κανόνες του προγράμματος.
</details>

<details>
<summary><b>Καταγράφεται ιστορικό για την εργασία μίας ερώτησης;</b></summary>

Όχι ακόμη. Προς το παρόν, το τοπικό ιστορικό καταγράφεται μόνο για την κλασική φόρμα τεσσάρων ερωτήσεων.
</details>

<details>
<summary><b>Πώς επαναφέρω τα προεπιλεγμένα πλήκτρα;</b></summary>

Χρησιμοποιήστε το εικονίδιο επαναφοράς δίπλα σε ένα τροποποιημένο πλήκτρο, το **Reset all** στο παράθυρο Hotkeys ή το **Reset** στις ρυθμίσεις· η τελευταία επιλογή επαναφέρει επίσης ήχο και κινούμενα εφέ.
</details>

## Αρχιτεκτονική

Το DemoScope είναι μία αυτοεκτελούμενη συνάρτηση (`@run-at document-start`, `@noframes`). Η `init()` εντοπίζει τον τύπο σελίδας, ελέγχει ότι αναγνωρίζεται και συνδέει τις παρακάτω μονάδες. Η πλήρης αναφορά και των 217 συναρτήσεων ανώτατου επιπέδου, με παραμέτρους, επιστρεφόμενες τιμές και κλειδιά αποθήκευσης, βρίσκεται στο [el_FUNCTIONS.md](https://github.com/ebayybe/DemoScope/blob/main/docs/el_FUNCTIONS.md).

| `Resilience` | Απομονωμένα βήματα, εναλλακτικές αναζητήσεις, απενεργοποίηση, διαγνωστικά | `safeStep`, `disableDemoScope`, `buildDiagnosticsReport` |
| `Bootstrap` | Σημείο εισόδου | `init`, `enhanceLayout` |

</details>

## Απόρρητο

Το DemoScope δεν στέλνει τηλεμετρία και δεν ανεβάζει ρυθμίσεις ή ιστορικό. Κατά την υποβολή ετυμηγορίας, το VACNet τη λαμβάνει μέσω της συνηθισμένης φόρμας του ιστότοπου. Οι ρυθμίσεις και το ιστορικό παραμένουν στο πρόγραμμα περιήγησης: στο `localStorage` (κλειδιά που ξεκινούν με `demoscope`) και στο `sessionStorage`. Επιλέξτε **Settings → Local history → Clear history** για να διαγράψετε το ιστορικό. Η διαγνωστική αναφορά αντιγράφεται μόνο στο πρόχειρο· εσείς αποφασίζετε αν θα τη μοιραστείτε.

## Αποποίηση ευθύνης
