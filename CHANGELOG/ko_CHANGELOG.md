# DemoScope v1.0.0

CS2 VACNet 검토 페이지용 userscript 도구 모음 DemoScope의 첫 공개 릴리스입니다.

### 추가 사항
- 29개 언어 인터페이스, 자동 언어 선택, 빠른 판정 프리셋 5개와 확장 조합 15개.
- 클립 구간 동영상 제어, 프레임 단위 이동, Shift 가속, Space 재생/일시정지, M 음소거, F 전체 화면, Enter 2단계 제출.
- 제한을 설정할 수 있는 로컬 기록, JSON 가져오기/내보내기, HTML 보고서, 여러 JSON 백업 병합.
- 개선된 초대 페이지, 사운드 설정, 변경 가능한 단축키, 계정 이름 숨기기, 검토 규칙, 기본적으로 꺼져 있는 선택형 무작위화 기능.

### 개인정보 보호
- 원격 측정 데이터를 보내지 않으며 로컬 데이터를 업로드하지 않습니다. 제출된 판정은 사이트 기본 양식을 통해 VACNet으로 전송됩니다.
