# DemoScope v1.0.0

รุ่นสาธารณะครั้งแรกของ DemoScope ชุดเครื่องมือ userscript สำหรับหน้าตรวจสอบ CS2 VACNet

### เพิ่มใหม่
- อินเทอร์เฟซ 29 ภาษา เลือกภาษาอัตโนมัติ ชุดคำตัดสินด่วน 5 แบบ และชุดผสมเพิ่มเติม 15 แบบ
- ควบคุมวิดีโอในช่วงคลิป เลื่อนทีละเฟรม เร่งด้วย Shift, Space เล่น/หยุด, M ปิดเสียง, F เต็มหน้าจอ และส่งคำตัดสินสองขั้นตอนด้วย Enter
- ประวัติในเครื่องที่กำหนดขีดจำกัดได้ นำเข้า/ส่งออก JSON รายงาน HTML และรวมไฟล์สำรอง JSON
- หน้าคำเชิญที่ปรับปรุงแล้ว การตั้งค่าเสียง ปุ่มลัดที่เปลี่ยนได้ ซ่อนชื่อบัญชี กฎการตรวจสอบ และตัวสุ่มคำตัดสิน (ปิดไว้โดยค่าเริ่มต้น)

### ความเป็นส่วนตัว
- ไม่มีการส่งข้อมูลเทเลเมตรีหรืออัปโหลดข้อมูลในเครื่อง คำตัดสินที่ส่งจะไปยัง VACNet ผ่านแบบฟอร์มปกติของเว็บไซต์
