# DemoScope v1.0.0

DemoScope 首個公開版本：用於 CS2 VACNet 審查頁面的使用者指令碼工具組。

### 新增
- 支援 29 種語言、自動選擇語言、五個快速判定預設與 15 種進階組合。
- 片段範圍內的影片控制、逐格檢視、Shift 加速、Space 播放/暫停、M 靜音、F 全螢幕，以及按 Enter 分兩步提交判定。
- 可設定的本機審查歷史、JSON 匯入/匯出、HTML 報告，以及合併多份 JSON 備份。
- 改良邀請頁面、音效設定、可變更的設定快捷鍵、隱藏帳戶名稱、審查規則對話框，以及預設關閉的選用判定隨機器。

### 隱私
- 不會傳送遙測資料，也不會上傳本機設定或歷史記錄。提交的判定會透過網站標準表單傳送至 VACNet。
