# DemoScope v1.0.0

CS2 VACNet 審査ページ向け userscript ツール、DemoScope の初回公開リリースです。

### 追加
- 29 言語のインターフェース、自動言語選択、5 種のクイック判定プリセット、15 種の拡張組み合わせ。
- クリップ区間内の動画操作、コマ送り、Shift 加速、Space 再生/一時停止、M ミュート、F 全画面、Enter による 2 段階送信。
- 上限を設定できるローカル履歴、JSON のインポート/エクスポート、HTML レポート、複数 JSON バックアップの統合。
- 招待ページの改善、サウンド設定、設定用ホットキー変更、アカウント名の非表示、審査ルール、既定でオフの判定ランダマイザー。

### プライバシー
- テレメトリを送信せず、ローカルデータをアップロードしません。送信した判定はサイト標準フォームを通じて VACNet に送られます。
